## Dependency and asset review

The alpha has no npm production or development dependencies. Browser code uses platform APIs and system fonts; the Node preview uses Node built-ins; the Windows launcher uses installed .NET Framework system libraries. Node, the browser and .NET are not bundled. No third-party JavaScript, font CDN, analytics or Ko-fi widget script is loaded by the static app. Links to external services are ordinary user-activated links. Optional Node support delivery is disabled without configuration and is not included in the static app.

SVG/CSS illustrations are project assets. The README banner was supplied by the maintainer; the screenshot shows fictional application data. This review does not independently establish ownership of supplied artwork. GitHub Actions and locally used build tools are development services/tools, not bundled runtime dependencies; their own licenses are unchanged.
